# TVC Electronics

ESP32-S3 双 IMU 云台控制固件及网页控制台。接线、校准、操作流程及实物验证边界见 [飞控说明](README_云台回中.md)。

双 IMU 按单主控 PCB 接入两块本地 MPU6050，共用 SDA9/SCL10。IMU1 为 0x68（AD0=GND、INT8），IMU2 为 0x69（AD0=3.3V、INT2）。两路安装方位均应用 −45° 参考，默认 X/Y 云台修正方向为 +1/−1。实物以各路标定及实际输出方向为准。

## 推力力矩稳姿

在新版工作台 Studio 的「真实飞控」→「推力力矩稳姿」填入 X/Y 目标倾角、推力标定、力矩 PID 和油门范围。X/Y 是以竖直为零的两向机体倾角，各可设为 −20°～+20°。运行中点击「更新目标角」，两轴参考以合成 4°/s 的上限移动。实测姿态与陀螺反馈每 10 ms 更新控制需求。

`ThrustTorqueControl.h` 将反馈和可选配平、重力补偿合成为两轴请求力矩（N·m）。分配器依据有效力臂、油门平方推力模型和可用云台偏转解算方位、俯仰与油门。偏转达到上限后才按需求提高油门，油门与舵机各自受限。方位转向期间，俯仰使用下一步可达方向上的投影；积分仅积累有助于实现的修正。

实物配置的 100% 油门按 Studio 当前正向电调窗口定义（停止 1500 μs，正向上端 1700 μs）。填入该上端实测推力乘以有效力臂，以及高于该电调起转阈值的基准油门与所需上限。配平和重力矩阵使用实测系数，默认填零。遥测的请求与分配力矩基于控制模型，实际电机推力或舵机角需要独立测量。

启动顺序为参数、目标、输出许可、舵机预定位、电调保持停止脉宽、显式启用闭环。IMU 超过 50 ms 未刷新或 Studio 心跳超过 1 s 时，退出推力闭环并停止电机和云台 PWM 输出。2.5.0 保留角度 PID、旧联动油门和手动输出用于兼容与检查。

2.5.1 的俯仰逻辑行程为 135° ±25°，对应 1315～1685 µs。物理 PWM 以已保存的俯仰中位为中心应用 ±25° 窗口，并受原绝对行程限制。方位的连续解将跨过 0° 或 360° 时，推力模式先向已标定的方位初始位返回。回位使用正常方位指令限速，电机维持基准油门，纠偏力矩沿估算可达方位投影，PID 积分暂停。中位的到位时序由 PWM 和舵机响应模型估计；机械回位速度和线束余量需要实物测量。

`GimbalPid` 可通过 `GimbalConfig.model` 接受外部标定的局部模型（静态偏置、重力矩阵和控制效能逆矩阵），将角加速度目标换算为推力纠偏向量，再解算舵角。`StartupPreposition` 与运行共用向量换算，保持限位和 PWM 限速。模型模式的 PID 输出单位是 °/s²，积分项和输出限幅也使用该单位；普通模式输出仍为纠偏角度。

模型模式在电机启动前选择靠近方位行程中部的等价舵角，减少释放后碰到行程端点时的大幅换向；普通 PID 仍选离已发送方位指令最近的解。到位判断依然只是基于 PWM 和等待时间，不能证明实际舵机已到位。

主控启动时从 `bench_config.h` 读取模型开关和参数；遥测 `control.model_enabled` 反映实际启用状态。默认关闭，参数占位为零；只有填写实测标定、重新整定 PID 并显式启用后才生效，无效矩阵会触发 PID_CONFIG 故障。网页目前不提供模型矩阵配置，重启恢复编译时配置；模型模式的方向由标定矩阵决定，普通模式的 X/Y 方向系数不参与模型换算。TVC Studio 的 SIL 模型系数不是实物标定。单一机械分支、小角度模型不能保证任意方位或大角度可用。测试见 `tests/model-control.test.cpp`。设计参考 [PX4 控制分配说明](https://github.com/PX4/PX4-user_guide/blob/main/en/concept/control_allocation.md)，未直接复制其实现。

编译主控前，将 `NetworkSecrets.example.h` 复制为 `NetworkSecrets.h`，设置自己的 Wi-Fi 热点密码；该文件被 Git 忽略，不要提交。该密码需要符合 ESP32 热点的 8–63 字节要求。使用已有设备时请沿用该设备的实际配置。

Arduino IDE 中打开 `TVC_Electronics.ino`，使用 Espressif ESP32 开发板包 3.3.12、ArduinoJson 7.4.3、WebSockets 2.7.2，并按飞控说明选择 ESP32-S3 配置。修改 `web/dist` 后运行 `node tools/embed_web.mjs`，更新固件内置网页资源。当前工程不含 SuperMini 采集板固件源码。

软件构建和仿真不等于实物验证；启动前预定位的舵机到位时间是估计值，没有位置反馈。操作电机前应拆桨确认舵机方向、电调停止脉宽和实际跟随时间。

- 双路本地 I2C 的假硬件测试通过：0x68/INT8 与 0x69/INT2 独立采样、200Hz、缺失模块不阻塞另一块、读取错误与恢复、禁止重复样本、遥测引脚与中断计数。

- 网页 dashboard、DOM、IMU2 监测、本地单文件入口和 32 项启停回归通过，包含本地 IMU1 的协议验证、来源标签、数据源切换及零样本故障说明。

## 2.4.5 同向安装验证（2026-11-08）

两模块同面同向，IMU1 与 IMU2 现在均使用 -45° 方位参考。1307 项云台/姿态映射/PID 检查通过，包括两路相同原始向量映射到相同机体 X/Y，以及保留 Y 向纠偏反转；网页数据源与本地入口测试通过。ESP32-S3 完整编译通过：程序 1,086,882 字节，静态 RAM 52,924 字节。未上传或验证实物机械动作；共同方位相对机构的绝对方向仍需实际小幅倾斜确认。


## 2.4.6 舵机指令速度（2026-11-08）

两路舵机共用的 SERVO_SLEW_US_PER_TICK 从 3 提高到 10：100Hz 控制循环中，每次指令最多变化 10μs，相当于 1000μs/s，约为原来的 3.33 倍。按当前脉宽映射，方位指令上限为 180°/s、俯仰指令上限为 135°/s。手动、自动回正和启动预定位都使用该限制；实际机械速度受舵机、供电和负载限制。启动预定位到达目标 PWM 后仍保持 2000ms 等待。

2.4.6 验证：完整 ESP32-S3 编译通过（程序 1,086,882 字节，静态 RAM 52,924 字节）；1307 项云台/PID 检查、启动预定位与 PWM 等待检查、本地网页入口检查通过。未代为上传或测量实际舵机速度。


2.4.8 按台架实测把方位机械中位校准到现有滑块的 230°（1778 μs），俯仰中位为 135°（1500 μs）。新版 Studio 的「机械回中」以设备回传的方位零位为准。

- 俯仰舵机在 2.4.9 以 1500 μs 为中心反转 PWM。遥测 outputs.servo_pwm_us 显示输出脉宽，原有舵角字段显示逻辑指令。
