# IMU2 I²C 读取测试

在 Arduino IDE 中打开 `IMU2_I2C_Read_Test.ino`。选择当前使用的 ESP32-S3 开发板及 USB 设置，确认端口后上传，打开串口监视器并设为 **115200 baud**。原生 USB 连接使用 USB CDC On Boot。

程序读取主控本地 IMU2：SDA 为 GPIO9、SCL 为 GPIO10、地址为 0x69（AD0 接 3.3 V）。它直接轮询寄存器，不依赖 INT/GPIO8，不输出电机或舵机信号。串口显示的是传感器自身坐标系，不能直接当成箭体姿态。

静止时加速度三轴的合量通常接近 1 g，旋转或移动传感器时读数应变化。若提示无法读取，检查供电、I²C 接线及 AD0；若读到的 WHO_AM_I 不是 0x68，记录实际值和传感器型号，勿盲目修改身份判断。

**上传测试程序会替换当前飞控固件**；完成测试后需重新上传 `TVC_Electronics.ino` 才能恢复飞控功能。保持电机停止；本测试不验证舵机方向或控制效果。
